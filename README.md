# Md Nafiz Gaffar — Research Portfolio

This is a clean academic portfolio designed for PhD applications, research networking and selected project presentation.

## Publish on GitHub Pages
1. Create a public GitHub repository named `nafizgaffarcccu-Hub.github.io` if you want the cleanest URL, or use a normal repository such as `research-portfolio`.
2. Upload `index.html`, `styles.css`, and the CV PDF to the repository root.
3. Open GitHub repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`, then save.
5. GitHub will show the live website URL after deployment.

Later, add your dissertation, publications, posters, deployed demos and stronger research projects as they become ready.
